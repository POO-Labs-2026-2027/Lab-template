# Github Lab Submission Guidelines

## Create PRs only with the code for this week's lab.

## Make sure you've not added code from another lab.

## Only approve the PR after you've received at least one round of review or a ✔️

## Name every IntelliJ project "lab-xx" (eg. for the second lab, it would be "lab-02"), and for each exercise create a package called "ex-xx" (eg. "ex-01").

## When you submit the code on DevMind, don't forget to have it all in one file, and without the "package org.(path.to.class);"
